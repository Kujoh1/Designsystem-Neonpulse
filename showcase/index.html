01 · AnsatzApproach

Cyberpunk, aber ruhig.

Cyberpunk, but calm.

Dunkle Neon-Oberflächen kippen schnell ins Laute: Glow auf jeder Karte, zu wenig Kontrast, jede Komponente mit eigenen Farben. NeonPulse setzt dagegen sechs klare Prinzipien, die jede Entscheidung im System begründen. Drei davon im direkten Vergleich:

Dark neon interfaces tip into noise fast: glow on every card, too little contrast, every component with its own colours. NeonPulse counters that with six clear principles that justify every decision in the system. Three of them, side by side:

PrinzipPrinciple 01

Dunkel ist die Leinwand, Neon das Signal

Dark is the canvas, neon is the signal

Rund 90 % der Fläche sind Near-Black und Grau. Neon markiert ausschließlich, was interaktiv oder live ist – dadurch weiß das Auge sofort, wohin.

Roughly 90% of the surface is near-black and grey. Neon only marks what is interactive or live — so the eye knows instantly where to go.

02 · ArchitekturArchitecture

Fünf Ebenen, ein Vertrag.

Five layers, one contract.

Jede Ebene baut nur auf der darunterliegenden auf. Komponenten konsumieren ausschließlich semantische Aliase, nie Rohwerte. Ein Rebrand oder ein neues Theme ist damit eine Änderung an einer Stelle – statt Suchen-und-Ersetzen im ganzen Code.

Each layer only builds on the one below it. Components consume semantic aliases only, never raw values. A rebrand or a new theme becomes a change in one place — instead of find-and-replace across the codebase.

Zwei Token-Ebenen trennen Wert und Bedeutung. Designer:innen und Entwickler:innen sprechen über --color-accent, nicht über #00e5ff – und Light Mode ist nur eine zweite Belegung derselben Namen.

Two token tiers separate value from meaning. Designers and developers talk about --color-accent, not #00e5ff — and light mode is just a second set of values for the same names.

Zustände (Hover, Fokus, Aktiv, Laden, Deaktiviert) werden aus Interaction-Tokens und Pseudo-Klassen abgeleitet – einmal definiert, überall identisch.

States (hover, focus, active, loading, disabled) are derived from interaction tokens and pseudo-classes — defined once, identical everywhere.

03 · Theming

Ein Attribut. Ein neues Theme.

One attribute. A new theme.

Probier es aus: gleiche Komponenten, gleiches Markup – nur das Theme-Attribut und zwei Primitives ändern sich. Der Light Mode hält dabei dieselben Kontrastregeln ein wie Dark.

Try it: same components, same markup — only the theme attribute and two primitives change. Light mode keeps the same contrast rules as dark.

06 · QualitätQuality

Gebaut wie ein Produkt.

Built like a product.

Barrierearm

Accessible

WCAG-AA-Kontrast für jedes Text-Token – in beiden Themes nachgerechnet. Sichtbarer Fokus-Ring für jedes Control, echte Checkboxen als Switches, prefers-reduced-motion wird respektiert.

WCAG AA contrast for every text token — verified in both themes. A visible focus ring on every control, real checkboxes behind switches, prefers-reduced-motion respected.

Single Source of Truth

Eine CSS-Datei enthält alle Tokens und Klassen. Die Doku liest Swatches, Kontrastwerte und die Token-Tabelle direkt daraus – es gibt keine Kopien, die veralten können.

One CSS file holds every token and class. The docs read swatches, contrast ratios and the token table straight from it — there are no copies that can drift.

Theming

Dark und Light über ein einziges Attribut – auch verschachtelt, etwa eine helle Insel auf einer dunklen Seite. Glows, Ringe und Verläufe leiten sich aus den Markenfarben ab.

Dark and light through a single attribute — even nested, like a light island on a dark page. Glows, rings and gradients are derived from the brand hues.

Performance & Datenschutz

Performance & privacy

Kein Build-Step, kein Framework-Zwang. Variable Fonts selbst gehostet (keine Requests an Google, DSGVO-freundlich), CDN-Abhängigkeiten exakt gepinnt und per SRI-Hash abgesichert.

No build step, no framework lock-in. Variable fonts are self-hosted (no requests to Google), CDN dependencies are pinned exactly and secured with SRI hashes.

Lebende Doku

Interaktive Referenz mit Theme-Umschalter, Suche per ⌘K, Copy-to-Clipboard und dem Quelltext jedes Specimens – veröffentlicht per Git-Push auf GitHub Pages.

An interactive reference with theme switch, ⌘K search, copy-to-clipboard and the source of every specimen — published to GitHub Pages with a git push.

KI-ready

AI-ready

CLAUDE.md und SKILL.md beschreiben Regeln, Struktur und Konventionen maschinenlesbar. Coding-Agents bauen damit on-brand UI statt generischer Oberflächen.

CLAUDE.md and SKILL.md describe rules, structure and conventions in a machine-readable way, so coding agents build on-brand UI instead of generic screens.
